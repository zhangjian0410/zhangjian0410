### 把做过的工作，变成下次能用的方法。

Hi, I'm **Archer**. I build portable tools for AI-assisted work.

我关注 AI 工作中的三个问题：怎样保留有用的上下文，怎样接续未完成的任务，以及怎样从实际工作中积累可复用的经验。

[**学习 Skill Engineering ↗**](https://skill-engineering-guide.pages.dev/) · [浏览我的开源项目](https://github.com/zhangjian0410?tab=repositories)

## 我在探索

- **可移植的 Skill**：把方法写成能阅读、能维护、能分享的能力。
- **持续的工作上下文**：让新会话知道从哪里开始、还有什么未完成。
- **有证据的改进**：区分提出建议、实际采用和验证效果。
